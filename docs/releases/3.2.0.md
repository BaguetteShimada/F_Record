## F_Record 3.2.0

- 增加 Photoshop 2025（26.x / CEP 12）支持，并继续支持 Photoshop 2022–2024。
- 更新 CEP 面板界面和交互。
- 提高视频导出的可靠性：使用独立 Node.js worker，增加超时、错误诊断与 Node.js 路径发现。
- 增加配置校验并清理 Generator 监听器，减少无效配置和重复监听造成的问题。
- 增加可复现的 Windows、pnpm、GitHub Actions 检查和自动发布流程。
- 发布包不包含 ffmpeg 或 ffprobe，需要使用系统中安装的可执行文件。

### 安装

1. 下载本 Release 的 [F_Record.zip](https://github.com/BaguetteShimada/F_Record/releases/download/3.2.0/F_Record.zip) 资产并解压。不要下载 GitHub 自动生成的 `Source code` 压缩包，它们不是可安装的插件包。
2. 关闭 Photoshop，在解压目录中打开管理员 PowerShell。
3. 默认安装到 Photoshop 2025：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\installPhotoshopPlugin.ps1
   ```

   Photoshop 安装在其他位置时，请指定主目录：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\installPhotoshopPlugin.ps1 -PhotoshopRoot "D:\Adobe Photoshop 2025"
   ```

安装前请确认系统可以运行 `ffmpeg`、`ffprobe` 和 `node`。也可以分别通过 `F_RECORD_FFMPEG_PATH`、`F_RECORD_FFPROBE_PATH` 和 `F_RECORD_NODE_PATH` 指定这些程序的完整路径。

如果无法使用安装脚本，可以沿用 Photoshop 2022 版本的手工安装布局：

- 将 `com.f_know.f_record.cep` 复制到 Photoshop 主目录下的 `Required\CEP\extensions`。
- 将 `com.f_know.f_record.generator` 复制到 Photoshop 主目录下的 `Plug-ins\Generator`。

目标目录不存在时请手动创建。安装后，在 Photoshop 的“编辑 → 首选项 → 增效工具”中启用 Generator 和旧版扩展面板，然后从“窗口 → 扩展（旧版）”打开 F_Record。
